# 8. Progress Update Rules

Whenever a lesson is completed:

1. Update its status.
2. Record the completion date.
3. Record exercise results.
4. Record knowledge-check results.
5. Record unresolved difficulties.
6. Update phase progress.
7. Update the current lesson.

A lesson can only become Completed when:

- Required content has been studied.
- Mandatory exercises have been completed.
- Assessment requirements have been satisfied.
- The result has been reviewed.

The next lesson must not be started automatically if the previous lesson has unresolved mandatory requirements.
