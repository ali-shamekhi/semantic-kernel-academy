
# Semantic Kernel Academy

A structured, documentation-based learning program for building production-grade AI applications using Microsoft Semantic Kernel, C#, ASP.NET Core, and .NET 10.

## 1. معرفی دوره

Semantic Kernel Academy یک برنامه آموزشی ساختاریافته برای یادگیری طراحی، توسعه، آزمایش و نگهداری نرم‌افزارهای مبتنی بر هوش مصنوعی در اکوسیستم Microsoft است.

هدف این دوره صرفاً یادگیری APIهای کتابخانه Semantic Kernel نیست؛ هدف نهایی، توانایی طراحی معماری نرم‌افزارهایی است که بتوانند از مدل‌های زبانی، ابزارهای خارجی، حافظه، دانش سازمانی و Agentها به شکل کنترل‌شده و قابل نگهداری استفاده کنند.

این دوره با رویکرد Documentation-based و در قالب 66 روز آموزشی طراحی شده است.

## 2. اهداف آموزشی

در پایان دوره انتظار می‌رود دانشجو بتواند:

1. معماری و مفاهیم پایه Generative AI و LLM را درک کند.
2. تفاوت Model، Provider، SDK و AI Framework را تشخیص دهد.
3. معماری داخلی Semantic Kernel را توضیح دهد.
4. Kernel و AI Services را در یک برنامه C# پیکربندی کند.
5. Semantic Kernel را با ASP.NET Core و Dependency Injection یکپارچه کند.
6. با Prompt Engineering و Prompt Templates کار کند.
7. Pluginهای Native و Semantic طراحی کند.
8. Function Calling و Tool Invocation را پیاده‌سازی کند.
9. Context و Conversation History را مدیریت کند.
10. Embedding و Vector Search را درک و پیاده‌سازی کند.
11. معماری Retrieval-Augmented Generation (RAG) طراحی کند.
12. منابع اطلاعاتی سازمانی را به AI Application متصل کند.
13. Agentها و Workflowهای هوشمند طراحی کند.
14. سیستم‌های Multi-Agent را تحلیل و پیاده‌سازی کند.
15. امنیت، Observability، Resilience و Performance را در AI Applications رعایت کند.
16. یک AI Application قابل استقرار در محیط Production طراحی کند.

## 3. مخاطب دوره

این دوره برای توسعه‌دهندگان Backend و Software Engineers طراحی شده است که:

- با C# آشنا هستند.
- تجربه توسعه با ASP.NET Core دارند.
- با Dependency Injection آشنا هستند.
- مفاهیم REST API و Software Architecture را می‌شناسند.
- تجربه کار با Database و SQL Server دارند.
- در Semantic Kernel و اکوسیستم AI مبتدی هستند.

آموزش مبانی C# و ASP.NET Core جزو اهداف دوره نیست.

## 4. فناوری‌های اصلی

| Technology | Role |
|---|---|
| C# | زبان اصلی توسعه |
| .NET 10 | Runtime و Development Platform |
| ASP.NET Core | ساخت AI Web Applications |
| Microsoft Semantic Kernel | AI Integration SDK |
| Microsoft.Extensions.DependencyInjection | Dependency Management |
| Microsoft.Extensions.AI | AI Abstractions در بخش‌های مرتبط |
| SQL Server | ذخیره‌سازی اطلاعات ساختاریافته |

انتخاب Provider، Vector Database و Packageهای جانبی در درس مربوطه و با بررسی مستندات رسمی انجام می‌شود.

## 7. قوانین آموزشی

- یک درس اصلی در هر روز آموزشی.
- هیچ درسی بدون درنظرگرفتن Prerequisites شروع نمی‌شود.
- مطالب قبلاً تکمیل‌شده بدون ضرورت تکرار نمی‌شوند.
- APIهای Deprecated در مثال‌های جدید استفاده نمی‌شوند.
- مثال‌های C# تا حد امکان قابل کامپایل هستند.
- نسخه Packageها در هر درس مشخص می‌شود.
- رفتارهای وابسته به نسخه صریحاً اعلام می‌شوند.
- معماری و Execution Flow در کنار APIها آموزش داده می‌شود.
- مثال‌ها باید کاربرد واقعی در ASP.NET Core داشته باشند.
- تفاوت Semantic Kernel و Microsoft Agent Framework رعایت می‌شود.
- منابع رسمی Microsoft و GitHub اولویت دارند.
